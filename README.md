Online Auction Management System

The Online Auction Management System is a web-based application designed to conduct auctions digitally. It allows sellers to list products with details such as images, starting price, and auction duration, while buyers can browse available items and place bids. The system tracks bids, displays the highest bid, and automatically identifies the winning bidder when the auction ends.

The project aims to provide a simple, transparent, and efficient platform for conducting online auctions with features such as user authentication, product listing, real-time bidding, auction management, and winner selection
